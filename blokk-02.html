Mit lát a sor.split()?

Kattints egy naplósorra, és nézd meg, milyen sorszámot kap az egyes szavak. Utána válassz egy sorszámot: a jobb oldalon az látszik, amit egy Counter a 12 mintasorból megszámolna. A számozás 0-tól indul.

Ugyanez a minta oldja meg a 2. és a 3. küldetést, csak a teljes, 371 soros naplón.

Eligazítás · a zsebkés öt pengéje

Amit a laborhoz tudni kell

Minden kódrészlet kimásolható, és a Colabban azonnal futtatható.

1 · Változók és típusok

eszkoz = "web-01"        # str: szöveg
hibak = 72               # int: egész szám
eszkozok = ["fw-main", "web-01"]   # list
sla = {"P1": "15 perc", "P2": "1 óra"}  # dict
print(eszkoz, hibak, eszkozok[0], sla["P2"])
→ web-01 72 fw-main 1 óra

A szöveg idézőjelben áll, a szám nem. A lista [ ], a szótár { }.

2 · Darabolás és keresés

sor = "2026-11-12 02:31:44 web-01 WARNING SSHD: Failed password for root from 185.23.41.7 port 51322"
reszek = sor.split()
print(reszek[3])                   → WARNING
print("Failed password" in sor)    → True
ip = sor.split(" from ")[1].split()[0]
print(ip)                          → 185.23.41.7

A split(" from ") a „from” szónál vág ketté; az [1] a második fele.

3 · Ciklus és feltétel

for sor in sorok:              # minden soron végig
    reszek = sor.split()
    if reszek[3] == "ERROR":   # csak a hibák
        print(reszek[2], reszek[1])

A 4 szóközzel beljebb kezdett sorok tartoznak a ciklushoz. Az = értéket ad, a == összehasonlít.

4 · Számlálás

from collections import Counter
szamlalo = Counter()
for e in ["web-01", "fw-main", "web-01"]:
    szamlalo[e] += 1
print(szamlalo.most_common(1))
→ [('web-01', 2)]

A most_common(n) a leggyakoribb n elemet adja, csökkenő sorrendben.
